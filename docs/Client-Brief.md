# Client Brief
 
## Project Title
 
SkillsTrack Learner Support Portal
 
## Client
 
SkillsTrack Training Centre
 
## Project Overview
 
The client requires a browser-based Learner Support Portal that allows learners to manage their learning activities in one place.
 
The system will allow learners to register and sign in, manage tasks, book support sessions, view their progress, access learning resources and play a coding mini-game.
 
Assessors will be able to view relevant learner activity and support bookings.
 
## Main Requirements
 
The system should allow learners to:
 
- Register for an account.
- Sign in securely.
- Create, view, update and delete tasks.
- Mark tasks as completed.
- View outstanding and completed work.
- Book support sessions.
- View their progress.
- Access learning resources.
- Play a coding mini-game.
 
The system should allow assessors to:
 
- View learner activity.
- View submitted support bookings.
- Update support booking status.
- View relevant learner information and results.
 
## Data Storage
 
The application will use Firebase to store and manage the required application data.
 
Firebase Authentication will be used for user authentication, while Firebase Realtime Database will be used for application data.
 
## Target Users
 
The main users of the system are:
 
- Learners
- Assessors
 
## Project Goal
 
The goal of the project is to create a simple and user-friendly portal that helps learners manage their learning activities and gives assessors access to relevant learner information and support bookings.
