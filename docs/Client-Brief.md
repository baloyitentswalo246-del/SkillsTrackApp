Client Brief SkillsTrack:
Training Centre requires a browser-based Learner Support Portal to bring learner goals, tasks, support bookings and progress information into one system.
The portal will allow learners to register, sign in, manage their learning tasks, book support sessions, review progress, use learning resources and complete a short coding game. 
The application will use JavaScript for application logic and Firebase Realtime Database for data storage.
Authentication will be used to manage registered users and their authenticated state
