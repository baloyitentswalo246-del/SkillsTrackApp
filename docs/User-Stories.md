# User Stories
 
## Learner User Stories
 
### Registration
As a learner, I want to register for an account so that I can access the SkillsTrack system.
 
### Login
As a learner, I want to log in so that I can access my learner dashboard.
 
### Task Management
As a learner, I want to create tasks so that I can keep track of my work.
 
As a learner, I want to view my tasks so that I can see what work I need to complete.
 
As a learner, I want to update my tasks so that I can change task information.
 
As a learner, I want to delete tasks so that I can remove tasks I no longer need.
 
As a learner, I want to mark tasks as completed so that I can keep track of my progress.
 
### Support Booking
As a learner, I want to book a support session so that I can get help with my work.
 
### Progress
As a learner, I want to view my progress so that I can see how much of my work I have completed.
 
### Game
As a learner, I want to play the coding game so that I can practise my skills.
 
As a learner, I want to see my game score so that I know how well I performed.
 
## Assessor User Stories
 
### View Learners
As an assessor, I want to view learners so that I can monitor their activities.
 
### View Learner Progress
As an assessor, I want to view learner progress so that I can see how learners are performing.
 
### Upload Tasks
As an assessor, I want to upload tasks for learners so that I can provide them with work.
 
### Manage Bookings
As an assessor, I want to view and manage support bookings so that I can organise learner support.
 
### Reports
As an assessor, I want to view reports so that I can monitor learner progress.
 
### Game Results
As an assessor, I want to view learner game results so that I can see their performance.
 
### Messages
As an assessor, I want to open learner messages so that I can respond to their questions or requests.
 
## Acceptance Criteria
 
The main features should:
 
- Work correctly when the user provides valid information.
- Show an appropriate message when information is missing or incorrect.
- Save required information correctly.
- Allow users to view the information they need.
- Be simple and easy to use.
