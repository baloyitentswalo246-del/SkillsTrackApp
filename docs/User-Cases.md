# Use Cases
 
## 1. Register Account
 
**Actor:** Learner
 
**Description:**  
The learner creates a new account to access the SkillsTrack system.
 
**Steps:**
1. Learner opens the registration page.
2. Learner enters the required information.
3. Learner clicks Register.
4. The system validates the information.
5. The account is created.
6. Learner can log in.
 
---
 
## 2. Login
 
**Actor:** Learner / Assessor
 
**Description:**  
The user logs into the system using their account details.
 
**Steps:**
1. User opens the login page.
2. User enters their email and password.
3. User clicks Login.
4. The system checks the details.
5. The user is taken to the correct dashboard.
 
---
 
## 3. Manage Tasks
 
**Actor:** Learner
 
**Description:**  
The learner manages their tasks.
 
**Steps:**
1. Learner opens Task Management.
2. Learner creates a task.
3. The task is saved.
4. Learner can view the task.
5. Learner can update the task.
6. Learner can mark the task as completed.
7. Learner can delete the task if needed.
 
---
 
## 4. Book Support Session
 
**Actor:** Learner
 
**Description:**  
The learner books a support session with an assessor.
 
**Steps:**
1. Learner opens Support Booking.
2. Learner selects a support topic.
3. Learner selects a date.
4. Learner adds any required information.
5. Learner submits the booking.
6. The booking is saved.
 
---
 
## 5. Manage Bookings
 
**Actor:** Assessor
 
**Description:**  
The assessor views and manages learner support bookings.
 
**Steps:**
1. Assessor opens the bookings section.
2. Assessor views learner bookings.
3. Assessor selects a booking.
4. Assessor updates the booking status.
5. The updated information is saved.
 
---
 
## 6. View Learner Progress
 
**Actor:** Learner / Assessor
 
**Description:**  
The system displays learner progress based on completed and outstanding tasks.
 
**Steps:**
1. User opens the progress section.
2. The system retrieves task information.
3. The system calculates progress.
4. The progress is displayed.
 
---
 
## 7. Play Game
 
**Actor:** Learner
 
**Description:**  
The learner plays the coding game and receives a score.
 
**Steps:**
1. Learner opens the game.
2. Learner answers the questions.
3. The system checks the answers.
4. The score is calculated.
5. The result is saved.
6. The learner can view the score.
 
---
 
## 8. View Game Results
 
**Actor:** Assessor
 
**Description:**  
The assessor views game results for learners.
 
**Steps:**
1. Assessor opens Game Results.
2. Assessor selects a learner.
3. The system displays the learner's game score.
4. Assessor can view the result.
 
---
 
## 9. View Reports
 
**Actor:** Assessor
 
**Description:**  
The assessor views learner reports and progress.
 
**Steps:**
1. Assessor opens Reports.

3. The system retrieves the information.
4. The report is displayed.
 
---
 
## 10. Open Messages
 
**Actor:** Assessor
 
**Description:**  
The assessor opens messages sent by learners.
 
**Steps:**
1. Assessor opens Messages.
2. Assessor selects a message.
