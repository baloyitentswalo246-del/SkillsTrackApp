#Use Cases:

##1. Login
Learner opens the login page.
Learner enters email and password.
System validates the input.
Authentication checks the credentials.
Successful login takes the learner to the dashboard; invalid details show feedback.

##2. Create Task
Learner opens the task manager.
Learner enters task information.
System validates the input.
Task is saved to Firebase.
The new task is displayed.

##3. Book Support
Learner opens support booking.
Learner enters the topic, preferred date and notes.
System validates the information.
Booking is saved.
A success or error response is displayed.

##4. Delete Task
Learner selects a task to delete.
System displays a confirmation dialog.
Learner confirms deletion.
Task is removed from the database and interface.
