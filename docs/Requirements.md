# Requirements
 
## Functional Requirements
 
The SkillsTrack Learner Support Portal should provide the following functions.
 
### 1. User Registration
 
- Learners must be able to create an account.
- The system must collect the required registration information.
- The system must validate the information entered.
 
### 2. User Login
 
- Learners and assessors must be able to log in.
- The system must check the user's login details.
- Users must be able to log out.
 
### 3. Task Management
 
Learners must be able to:
 
- Create tasks.
- View tasks.
- Update tasks.
- Delete tasks.
- Mark tasks as completed.
- View outstanding tasks.
- View completed tasks.
 
### 4. Support Booking
 
Learners must be able to:
 
- Select a support topic.
- Select a preferred date.
- Add notes about the support they need.
- Submit a support booking.
 
Assessors must be able to:
 
- View submitted support bookings.
- Update the booking status.
 
### 5. Learner Progress
 
The system should display:
 
- Total tasks.
- Completed tasks.
- Outstanding tasks.
- Calculated learner progress.
 
### 6. Game
 
Learners should be able to:
 
- Open the coding game.
- Play the game.
- Receive a score.
- View their game result.
 
Assessors should be able to view learner game results.
 
### 7. Reports
 
The system should allow relevant learner information and progress to be viewed in reports.
 
### 8. Firebase
 
The application will use Firebase for:
 
- User authentication.
- Storing application data.
- Retrieving application data.
- Updating application data.
- Deleting data where required.
 
## Non-Functional Requirements
 
### Usability
 
- The system should be simple and easy to use.
- Navigation should be clear.
- Buttons and forms should be easy to understand.
 
### Performance
 
- Pages should load within a reasonable time.
- Data should be saved and retrieved efficiently.
 
### Security
 
- Users should log in using their own accounts.
- Learner information should be protected.
- Users should only access information they are allowed to see.
 
### Compatibility
 
The application should work correctly in Google Chrome and modern web browsers.
 
### Maintainability
 
- Code should be organised.
- The team should use Git and GitHub to manage changes.
- Documentation should be kept up to date.
