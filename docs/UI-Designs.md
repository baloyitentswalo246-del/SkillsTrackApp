# Test Plan
 
## 1. Purpose
 
The purpose of this test plan is to make sure that the SkillsTrackApp Learner Support Portal works correctly and meets the project requirements.
 
Testing will be done throughout the development of the application to find and fix errors.
 
## 2. Login and Registration Testing
 
We will test that:
 
- Learners can register successfully.
- Learners can log in with the correct details.
- Incorrect login details show an error message.
- Required fields cannot be left empty.
- Users can log out successfully.
 
## 3. Task Management Testing
 
We will test that learners can:
 
- Create a new task.
- View their tasks.
- Update a task.
- Delete a task.
- Mark a task as completed.
- View outstanding tasks.
 
## 4. Support Booking Testing
 
We will test that:
 
- Learners can book a support session.
- Learners can enter the required information.
- The booking is saved correctly.
- The assessor can view the booking.
- The assessor can update the booking status.
 
## 5. Progress Testing
 
We will test that the system calculates learner progress correctly.
 
For example:
 
Total tasks = 10  
Completed tasks = 7  
Progress = 70%
 
The dashboard should display the correct:
 
- Total tasks
- Completed tasks
- Outstanding tasks
- Calculated progress
 
## 6. Game Testing
 
We will test that:
 
- The game opens correctly.
- Learners can play the game.
- The score is calculated correctly.
- The game result is saved.
- The assessor can view the learner's game result.
 
## 7. Assessor Testing
 
We will test that the assessor can:
 
- View learners.
- Open learner progress.
- Upload learner tasks.
- View support bookings.
- Update booking status.
- Open learner messages.
- View game results.
- View reports.
 
## 8. Firebase Testing
 
We will test that:
 
- User information is stored correctly.
- Tasks are saved correctly.
- Support bookings are saved.
- Game results are saved.
- Data can be updated and retrieved correctly.
 
## 9. Validation Testing
 
We will check that:
 
- Required fields are completed.
- Invalid information is rejected.
- Appropriate error messages are displayed.
- Confirmation messages appear after successful actions.
 
## 10. Final Testing
 
After fixing errors, the team will test the features again to make sure they work correctly.
 
The final application should allow learners to register, manage tasks, book support sessions, view progress and play the game. Assessors should be able to view learner information, bookings, progress and game results.
